JIGSAW for OS/2 -- Version 1.1
===============================

Overview
--------
Jigsaw is an OS/2 Presentation Manager (PM) puzzle game.
Load any bitmap (.BMP) file and Jigsaw cuts it into 36 puzzle
pieces (6x6 grid) which are then jumbled on screen.  Drag pieces
with the mouse to reassemble the original image.

This is a 32-bit port of the original 16-bit Microsoft OS/2
sample application (c) 1988 Microsoft Corporation.


Controls
--------
  Ctrl+N or Game > Load Bitmap   Load a new .BMP file
  Ctrl+J or Game > Jumble        Scatter all pieces randomly
  Ctrl+F or Options > Frame      Toggle scrollbars and menu
  Ctrl++ or Options > Zoom In    Scale the puzzle view larger
  Ctrl+- or Options > Zoom Out   Scale the puzzle view smaller
  Options > Language             Choose display language
  Ctrl+X or Game > Exit          Quit


Files
-----
  bin\jigsaw.exe   The executable
  jigsaw.cfg       Settings saved on exit (created automatically)


Languages
---------
  English, Espanol, Nederlands, Deutsch, Francais, Italiano
